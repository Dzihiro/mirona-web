# MIRONA – web mirona.cz

Statický web ručního krejčovství MIRONA. Běží zdarma na GitHub Pages z větve `main`, doména mirona.cz je registrovaná u Forpsi.

- `index.html` – celá stránka (HTML + CSS v jednom souboru)
- `logo.png` – logo (průhledné pozadí)
- `img/` – fotky do úvodu a galerie
- `CNAME` – vlastní doména pro GitHub Pages (neměnit)

Ceník je v `index.html` připravený, ale skrytý (atribut `hidden` u sekce `#cenik`). Zobrazí se smazáním `hidden` a odkomentováním odkazu v menu.

Každá změna nahraná do `main` se na mirona.cz projeví zhruba do minuty.
